# Task 5 — Asymptotic Analysis

- Linear search: `O(n)` upper bound, `Ω(1)` lower bound, and `Θ(n)` average/worst growth under the usual search assumptions.
- Iterative binary search: `O(log n)` worst-case upper bound and `Θ(log n)` worst-case growth; best case is `Θ(1)`.
- Recursive binary search: `O(log n)` worst-case time and `Θ(log n)` recursion-stack space; best-case time is `Θ(1)`.

Asymptotic notation describes growth as input size increases and ignores machine-specific constants. It does not by itself predict exact seconds.
