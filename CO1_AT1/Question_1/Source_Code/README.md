# ShopSphere Scalability Audit – Source Code

## Course Details

* **Course Code:** CSA06
* **Course Name:** Design and Analysis of Algorithms
* **Assessment:** CO1 – Assessment Tool 1

## Description

This folder contains the Python implementation used to analyse the scalability of algorithms in the ShopSphere online shopping platform.

## Algorithms Analysed

1. M1 – Duplicate-Listing Detector
2. M2 – API Rate Limiter
3. M3 – Product Search
4. M4 – Recommendation Engine
5. M5 – Sales Analytics Engine
6. Nightly Report Generator

## Programming Language

Python 3

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the folder containing `daa_analysis.py`.
4. Execute:

```bash
python daa_analysis.py
```

## Expected Output

The program calculates operation counts and estimated execution times for the algorithms using a catalogue size of 1,000,000 products.

## Purpose

The implementation demonstrates algorithm analysis, asymptotic complexity, recurrence relations, and scalability evaluation.
